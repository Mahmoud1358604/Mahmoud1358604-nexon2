# WORLD LIFE v0.1 — Cairo Prototype

أول Prototype قابل للتشغيل للعبة محاكاة الحياة Multiplayer على الويب.

## المتطلبات
- Node.js 20+
- اتصال بالإنترنت لأول تحميل Phaser من CDN

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح:
- http://localhost:5173

لاختبار Multiplayer افتح نفس الرابط في نافذتين/متصفحين.

## الموجود في v0.1
- خريطة Cairo مصغرة
- حركة اللاعب بـ WASD / الأسهم
- Multiplayer عبر WebSocket
- رؤية اللاعبين الآخرين
- NPCs متحركة
- دردشة فورية
- وظيفة بسيطة تكسب منها 25 جنيه
- استئجار محل مقابل 100 جنيه والتحول إلى "صاحب محل"
- واجهة HUD
- سيرفر authoritative مبدئيًا للحركة والمال والوظيفة

## الخطوة التالية
إضافة نظام الحسابات/الشخصيات، ثم وظائف حقيقية، مخزون، محل فعلي، NPC replacement، وحفظ البيانات في قاعدة بيانات.
