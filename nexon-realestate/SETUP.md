# NEX•ON — تشغيل الموقع الجديد

## 1) رفع الموقع على GitHub
1. اعمل ريبو جديد على حسابك (Public — لازم يكون Public عشان GitHub Pages المجاني يشتغل وعشان الموقع يقدر يقرأ properties.json/partners.json من غير مفتاح).
2. ارفع كل الملفات دي (الفولدر ده بالكامل) في الريبو.
3. من إعدادات الريبو → Pages → اختار Source: Deploy from a branch → Branch: `main` / `root`.
4. هياخد كذا دقيقة والموقع هيبقى شغال على رابط زي:
   `https://<username>.github.io/<repo-name>/`

## 2) مفتاح الدخول للوحة التحكم (Personal Access Token)
عايز تعرف: تستخدم نفس مفتاح الموقع القديم ولا تعمل واحد جديد؟

**الإجابة التقنية:** استخدام نفس المفتاح مش هيأثر على الموقع القديم *لو* المفتاح فيه صلاحية على الريبو بتاع الموقعين الاتنين — المفتاح مجرد "تصريح دخول"، مش حاجة بتتستهلك أو تتشارك بينهم. لكن **الأفضل أمنيًا** إنك تعمل مفتاح جديد مخصص للريبو الجديد بس، عشان لو حصل تسريب لمفتاح، يتأثر موقع واحد بس مش الاتنين. وده اللي عملناه في اللوحة الجديدة: كل موقع بياخد owner/repo/token خاصين بيه، محفوظين على الجهاز بتاعك بس.

خطوات عمل مفتاح جديد:
1. على GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. حدد Repository access → Only select repositories → اختار الريبو الجديد بس.
3. Permissions → Contents → Read and write.
4. احفظ المفتاح، وأول ما تفتح `admin.html` هتحط فيه: اسم المستخدم/المنظمة، اسم الريبو، والمفتاح.

## 3) الحماية
مفيش يوزر وباسورد ثابت. أي حد معاه مفتاح صحيح لنفس الريبو بس هو اللي يقدر ينشر تعديلات — بالظبط زي نظام الموقع القديم. المفتاح بيتحفظ على متصفح جهازك بس (localStorage)، ومفيش سيرفر وسيط بيشوفه.

## 4) اللي اتضاف من لوحة الإدارة القديمة
- ربط حقيقي بـ GitHub بدل التخزين المحلي (كل حفظ بينشر فعليًا على الموقع لكل الزوار)
- رفع صور الوحدات مباشرة من جهازك (مش لازم روابط جاهزة)
- إدارة المكاتب الشريكة (إضافة/حذف، مع لوجو وموقع ونبذة) — وبتظهر في شريط تحت الوحدات بالموقع
- تنظيف الملفات الميتة (فحص أي صورة/لوجو مش مرتبط بوحدة أو مكتب شريك، واختيار حذفها)
- ترجمة كل أخطاء GitHub لرسائل عربية واضحة + إعادة محاولة تلقائية عند فشل الاتصال
- تحذير قبل مغادرة الصفحة أثناء رفع صور
- حماية من XSS في كل البيانات المعروضة (بالموقع العام ولوحة التحكم)
- زرار "مسح البيانات المحفوظة من الجهاز" في صفحة الدخول

## 5) حاجة واحدة اختلفت عن القديم
الموقع القديم كان بيدعم رفع فيديو لكل وحدة (مع صورة غلاف تلقائية). الموقع الجديد حاليًا بيدعم صور فقط (معرض صور متعدد) لأن تصميم البيانات الجديد مبني كده من الأساس. لو عايز الفيديو يترجع، قولّي وهضيفه.
